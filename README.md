# Learning c++

My journey learning c++.

## Motivation

I have wanted to learn c++ for a long time now for many reasons:
* I promised myself I would learn it.
* There are many cool projects I want to build using it.
* It will expose me to a lower layer of abstraction than languages I use day to day.
* Career prospects.
* It's fast.
* Why not...

## What is my plan?

Originally I was going to follow one of those 24 hour long youtube videos and call it a day.. literally, but after doing a bit of research (scrolling reddit) I decided that using [learncpp.com](https://learncpp.com) would be a better idea.

Due to the fact that I can get easily distracted when I find something interesting I got my good friend Claude to make me a plan on how to cover everything c++.

I now have a 26 week course which requires me to put in 8 hours of work a week. You can check more details in the [tracker](./tracker/). The goal is to learn concepts and spend enough time practicing writing actual code.
