Open your tracker folder

Click Connect tracker folder and choose the tracker folder in your copy of the repo. Chrome will ask whether this page may edit files there. After that, every change saves to the CSV files automatically.

Saving updates the files on your computer. Commit and push to update GitHub.

This browser can’t edit the tracker

Editing needs Chrome or Edge on a computer. You can still read the tracker: in a terminal, run python3 -m http.server inside the tracker folder and open http://localhost:8000.
